# Aurora Cloud Platform - Overview

Aurora Cloud is a managed compute platform for data and AI workloads. The company was
founded in 2019 and is headquartered in Krakow, Poland.

## Regions

Aurora Cloud operates in four regions:

- `eu-central-1` (Frankfurt, Germany)
- `eu-north-1` (Stockholm, Sweden)
- `us-east-1` (Virginia, United States)
- `ap-south-1` (Mumbai, India)

Each region has three independent availability zones. Data is stored in the region where
it is written and is not replicated across regions unless the customer explicitly enables
cross-region replication.

## Core services

- **Aurora Compute** - managed containers and batch jobs.
- **Aurora Vectors** - a vector database for embeddings and semantic search.
- **Aurora Flow** - a workflow engine for retrieval-augmented generation pipelines.
- **Aurora Lake** - an object storage layer for documents and model artifacts.
